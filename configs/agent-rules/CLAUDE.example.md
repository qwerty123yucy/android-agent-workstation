# PRoot + Termux 工作站全局规则模板（`~/.claude/CLAUDE.md`）

- **禁止跨工具调用交互式 TUI Agent**：任何情况下不得直接或间接启动 `agy` 等全屏交互式 Agent 进程，交互验证交由用户本人执行。
- **PRoot 容器约束**：当前处于 Termux PRoot `--isolated` 容器，不支持嵌套内核沙箱；检索文件优先使用原生工具或 `rg` / `fd`，互不依赖的只读检查尽量并行。
- **宿主机 ADB 红线**：未经用户明确授权不得读取或操作宿主机 Android 界面；获授权后所有命令显式加 `-s 127.0.0.1:5555`，严禁在容器内运行 `adb kill-server`，验收完毕强停目标测试 App 释放屏幕唤醒锁。
- **实测验证与失败收敛**：退出码 `0` 不替代目标状态验证；真正报错最多针对性重试一次，仍失败则保留现场并汇报根因。
- **风险与交付边界**：破坏性操作、公开推送、对外发送或路线取舍前先确认；源码与构建产物保持同源一致。
